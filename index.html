FAQ

Questions,
answered.

Is PaperPop free?

Yes. PaperPop is free to download and use.

Does it need the internet?

No. PaperPop works fully offline.

Where are my notes saved?

Only on your computer, in a local database with automatic backups. Export a .paperpop file any time and import it on another PC.

Microsoft Store or .exe?

The Store version is recommended: it installs without warnings and updates itself. The .exe is a direct install for people who prefer it. Install one, not both.

Can it start with Windows?

Yes. Turn on Start with Windows in Settings and your notes are waiting every time you log in.

How is PaperPop different from Windows Sticky Notes?

PaperPop is built to keep your checklist in sight: notes stay on top of other apps, use a handwriting font, and celebrate finished tasks with pen ticks and confetti. It works fully offline without any account.

Does PaperPop work on Windows 10?

Yes. PaperPop runs on both Windows 10 and Windows 11.
